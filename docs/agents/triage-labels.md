# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Maintainer must evaluate the issue |
| needs-info | `needs-info` | Waiting for missing information |
| ready-for-agent | `ready-for-agent` | Specified for agent work within Lane's approval boundaries |
| ready-for-human | `ready-for-human` | Requires human implementation |
| wontfix | `wontfix` | Will not be actioned |

Use these exact labels when a skill names a triage role. Preserve other descriptive labels such as `bug` and `enhancement`. Reuse existing labels rather than recreating them.
