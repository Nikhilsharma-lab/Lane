# Domain documentation

Lane is a single-context application. Read `GLOSSARY.md` for locked vocabulary, `AGENTS.md` for scope, `REQUIREMENTS.md` for behavior and decision status, and `lane-roadmap.md` for sequence. Read `docs/SESSION-STATE.md` when resuming work.

Read the relevant `docs/adr/` records before exploring the affected domain. If a future `GLOSSARY-MAP.md` exists, follow its relevant context pointers.

Use established domain terms in specs, issues and tests. Flag conflicts with canonical requirements or ADRs explicitly; distinguish newly approved target behavior from implemented and verified behavior. The issue tracker organizes work; it does not replace product authority or implementation approval.
