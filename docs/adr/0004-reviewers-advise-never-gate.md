# Reviewers advise and never gate pickup

Reviewers on a Request are optional and answer Looks good or Raise a concern; no answer, and no concern, ever
blocks pickup (2026-10-21). Picking up with open concerns or unanswered reviews asks "Pick up anyway?" and
proceeds on confirmation.

## Considered Options

- The named PM/Designer/Developer agreement gate (#58, approved earlier on 2026-10-21) and every later trio
  plan: superseded the same day. A gate keyed to profile labels made those labels permissions (see ADR 0006).

## Consequences

- Only Admins and Members, the paid seats, can be Reviewers.
- Editing what a Request says clears every answer, so a concern is always about the current version.
