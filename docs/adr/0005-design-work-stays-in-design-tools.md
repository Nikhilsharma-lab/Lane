# Design work stays in design tools

Design reviews, design decisions and customer journeys happen in the design tools teams already use; Lane keeps
a Design link and tracks the Request (reviews moved to Figma 2026-10-18; journeys 2026-10-24). This follows a
permanent principle: Lane connects the product-development journey and does not replace specialist tools that
already do a job well.

## Considered Options

- In-app Ask for review rounds (built 2026-10-09, migration `0018`): retired 2026-10-18.
- A maintained journey record inside Lane: refused by the 2026-10-24 product vision spec.

## Consequences

- This is not a Figma integration; that stays on the Do NOT build list.
- Saved review rounds keep only their Design link; the historical data stays stored.

Source: `REQUIREMENTS.md` decision log (2026-10-18), `docs/product-vision-spec.md`.
