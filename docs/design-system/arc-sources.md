# Arc UI source ledger for Lane product

Arc UI supplies Lane's product components and the current production visual theme. The approved Linear primitives preview is documented below. [The official docs](https://uiarc.dev/docs/introduction), [theming guide](https://uiarc.dev/docs/theming), and [AI/MCP guide](https://uiarc.dev/docs/ai) govern future changes. The marketing repository is outside this migration.

`src/components/arc/` contains official `@uiarc` registry source and licensed `@uiarc-pro` source retrieved through MCP. `arc-source-hashes.json` records the source URL, installed file, and upstream SHA-256. Changed local files are explicit adaptations. Free install IDs are `arc-foundation`, `alert`, `avatar`, `badge`, `button`, `checkbox`, `chip-group`, `floating-button-group`, `context-menu`, `dialog`, `drawer`, `dropdown-menu`, `empty-state`, `filter-toolbar`, `input`, `notification-center`, `pagination`, `password-field`, `popover`, `progress`, `radio-group`, `search-field`, `segmented-control`, `select`, `skeleton`, `sortable-data-table`, `textarea`, `toast-stack`, `tooltip`, and `user-menu`. The Pro block is `workspace-sidebar`. Free source docs are at `https://uiarc.dev/components/<id>`; the sidebar reference is `https://uiarc.dev/components/blocks/sidebar?variant=workspace-sidebar`.
