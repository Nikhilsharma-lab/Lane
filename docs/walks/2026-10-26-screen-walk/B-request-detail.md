# B: Request detail page (`/requests/[id]`) and its popups

## Covered
- **Requests walked:** LAN-1 (open), LAN-4 (in progress), LAN-6 (done), LAN-31 (Guest submission waiting to be taken on), LAN-30 (long title, 12 paragraphs, 25 comments including the 300-character string), LAN-7 (open). I also made my own Requests: LAN-32, 34, 35, 38, 39, plus two throwaway ones I deleted. Each has a "[B]" prefix. LAN-32 went Open → In progress → Done → Measuring. LAN-38 went Open → In progress → Done → "Is it live?" → Yes → Closed without a result. LAN-35 and LAN-39 went to Done via the "Is it live?" Escape and Not yet paths.
- **Sizes and themes:** 1440 light (every state and popup), 390 dark (every state, plus the properties drawer, More actions, status and priority menus, Edit, Delete, Is it live?, Link a Request and the reviewer picker), 768 light, 1024 dark, 1440 dark (axe on every state and popup), and 390×500 for the comment box with the on-screen keyboard up. No horizontal overflow at any size.
- **Popups:** status menu, priority menu, Add reviewer form and reviewer picker, Raise a concern, Pick up anyway?, Link a Request as Same problem (search, no match, link, Remove), Edit Request (Project, Labels, Metric, Measurement window, Custom date range calendar, Add link, review step, save), Delete (Cancel and a real delete), "Is it live?" (Escape, Not yet, Yes, and Undo pressed while it was open), Record release (inline and as a dialog), Correct release, Void incorrect release, Create follow-up Request, Close without a result (done for real on LAN-38), Add correction, phone properties drawer, phone More actions.
- **Reviewers:** `pm` asked `dev` to review LAN-34. `dev` raised a concern. `pm` saw the concern, then opened Pick up anyway? and cancelled it. `pm` then edited the Request, which cleared the concern.
- **Comments:** posted with the button, with ⌘/Ctrl+Enter, a very long one, and one while offline (back online, Try again worked). Comments have no edit or delete option, and comments can't take attachments.
- **Member view:** I looked at LAN-1, LAN-31 and LAN-32 as `dev`.
- **Keyboard:** full tab order, every picker by keyboard, Escape and where focus goes back. Plus loading (throttled), an offline link click, and the not-found Request page.
- **Not walked:**
  - "Take this on" on LAN-31: it would change seeded data.
  - "Close Request" with a measured result: it only opens on 25 Nov.
  - A created-date picker: the Request page has none, because Submitted is read-only.
